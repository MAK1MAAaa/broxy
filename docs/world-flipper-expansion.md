## 本批可玩内容

新增八件装备，保留原作开发ID和透明像素图。自动攻击、占格和下表数值为本游戏适配，不能当作原作装备倍率；Ⅰ／Ⅱ／Ⅲ阶按现有1／2／4权重计算。

| 武器 | Ⅰ阶装备效果 |
| --- | --- |
| 普罗米修斯之剑 | 每次主角技能累计2.5%回转，最高15%，只影响后续施法的冷却 |
| 马尔特 | 球化期间对敌伤害增加20% |
| 天羽羽斩 | 球化期间对敌伤害增加10% |
| 雷神之锤 | 对真正破防中的首领增加15%伤害；原作麻痹条件尚未接入 |
| 占事略决 | 仅球化撞敌增加25%伤害，对应原作Power Flip的本作改编 |
| 弯刀 | 生命上限增加8，购买只补上限增量 |
| 帕拉修 | 主角与背包技能伤害增加28%，不增加普通武器伤害 |
| 海姆达尔之剑 | 生命低于70%时回复上限的20%，同UID每波一次；每次有效回复累计3%伤害，最高15% |

武器被动随背包真实UID生效，移动／旋转不重置状态；出售撤销被动，同一UID重新投影不能刷新救命次数。买卖、合成与静态属性预测共用重算规则；满血、无效治疗和死亡不刷回复事件。伤害按真实来源统计，破防倍率只作用于首领。首波武器池限制实际报价不高于28魂屑，后续开放全目录，保留原最低收入和首店保障。

四名现有主角的R技能改为原作代表特征：

- 阿尔克「粉碎流星」：周围火伤，随后获得5秒20%攻击强化。
- 克拉莉丝「炼金爆发」：前方十二段伤害；结束后给命中敌人施加火属性易伤。
- 希尔媞「风神·解放」：前后双向斩击，读取真实球化连击增伤，最高50%。
- 花火「红牡丹」：五枚独立移动炸弹，扫掠检测敌人、弱点及场景障碍；碰撞或到期时范围爆炸，每枚只爆炸一次。

花火使用20枚炸弹和20个短暂爆炸回执的固定池；画面直接消费实际实体和爆炸位置，不再绘制虚构的瞬时直线攻击。阿尔克改为火焰冲击环，希尔媞显示前后两道青绿斩击；关闭闪光仍保留必要弹体和范围轮廓。玩家和敌方危险预警继续处于友方特效上方。普通爆破改为清晰的双层像素环，去除淡色铺底与平滑边缘，减少密集命中时遮住地面的灰雾；实际范围、伤害、寿命和数量上限保持。

尚未完成：克拉莉丝驱散、原作全队命中连击体系、协力球弹板反射、队长技和角色被动能力。三名背包后排仍保留此前脉冲／月弧／落星改编，尚未与新版R统一。十二段伤害在一次固定步结算，单人增益替代原作多队参战者效果；所有伤害、冷却、时长和成长仍为本游戏数值。

地图补充见[官方试玩地图补充](world-flipper-map-expansion.md)：新增星见镇、光之王座、魔塔之巅，共七张3444×1800竞技场、52处地形。原四图及原65张素材PNG字节保持。标题选择支持有边界的滚动和键盘焦点跟随；伤害结算可滚动查看全16件武器的历史记录。HUD、主角选择、现有背包操作与封面构图沿用。
