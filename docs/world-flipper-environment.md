# 原作场景、地面障碍与封面恢复

本轮修复敌人底部灰边，替换四张地图并加入实际障碍，封面恢复原天空遗迹构图。主角仍为阿尔克，多主角及抽取机制没有进入本轮。

## 敌人透明边缘

火精、瑞西塔尔的原GIF自带不透明 `#c4c4c4` 灰色接触影，叠在现有游戏阴影上形成灰条。`tools/world_flipper_enemies.json` 固定原图坐标、RGBA与预期数量，仅移除底部48／64个原生像素；身体、黑色轮廓及首领脸部的其他灰色保留。规范化时同步调整偏移，保持真实脚底在66／146像素处。其余三类敌人PNG字节保持。

处理器先检查整个素材组的SHA、尺寸、透明度与遮罩命中数量，再写输出，源图变化或非法遮罩不会覆盖已交付图片。没有把整张图片的灰色批量转透明。

`python tools/fetch_world_flipper_art.py --offline --references` 可用校验过的缓存重建28张素材，含四背景、四预览、三个道具和保留的历史封面底图。没有将新的AI封面误纳入公开原图重建。

## 地面障碍

每图10处独立低矮障碍使用官方试玩的石碑、花坛、弹板帧，排除图集1像素边框，按4／3／3倍nearest放入96像素画布，以 `(48,84)` 落脚。障碍配置和绘制、小地图共用 `data/arenas.json`。半径30—44像素，障碍间净距至少180像素，边界通道至少180像素；初始玩家和Boss位置分别保留240／160像素安全区。

`ArenaObstacles` 负责圆形扫掠、最多三次滑动和安全投影；大步长冲刺、秘术脉冲击退、接触反冲同样经过扫掠。敌人按实际身体半径缓存可见图和路线，移动目标累计偏移48像素后重算。冲锋方向保持锁定，撞障碍后按原时限恢复追击。出生线段先裁去障碍占地，再消耗原来的两次随机采样；召唤与初生掉落投影到安全位置。

碰撞热路径使用独立的128像素空间格与packed几何数组，格子预先包含障碍半径加64像素身体范围。小步同格移动只检查附近候选；跨格检查整段包络内的保守候选，身体半径大于64时回退全量窄相。同体型追逐同一精确目标时共享安全落点，跨格包络缓存最多4096项，重新配置时全部失效；没有缩减障碍或降低物理更新率。新格子分配独立候选数组，避免共享空数组污染；正负格边界、跨格大步长、超出索引体型及反复重配均有回归。空间索引只减少候选数量，圆形扫掠继续决定实际碰撞。

低矮障碍只阻挡地面身体。飞行武器、敌方弹体与吸起的魂屑可以越过，避免改变现有弹射、贯穿、归魂环和磁吸规则。磁吸在障碍两侧的真实收集有专项覆盖，未靠波末结算掩盖卡住。

## 封面

内置imagegen编辑原封面，将鸟喙巫师、书和杖替换为阿尔克，保留天空、浮空遗迹、金色天球环和平台构图。新图另存 `assets/title/cover-alk.png`，原有两套封面文件保留。生成结果按原比例居中归一化至1280×720，SHA与参考记录见 [cover-alk.image-generation.json](../assets/title/cover-alk.image-generation.json)。它是AI编辑图，使用原作角色立绘作身份参考。

`TitleCover` 显示单张复合底图，移除独立肖像层和选角API。24帧原生星点、环光、烛火每120ms推进，隐藏和退出时停止唯一计时器，不消耗战斗随机数。当前GIF为 `cover-alk.gif`，元数据 `cover-alk.animation.json` 记录实际底图、绘制器和24帧校验；打包器拒绝带UI或来自旧底图的捕获。

## 验证

本轮源代码、原生画面、Windows导出与资源校验的实际结果记录在 `reports/world-flipper-environment/validation.json`。完整回归入口为 `./tools/test.sh`，新增 `test_obstacles.gd` 和六项 `test_world_flipper_environment_assets.py`，日常素材测试不依赖源缓存、网络或Git。原生专项覆盖场景、地图、碰撞、技能、UI、封面和导出后的同一路径。画面捕获是固定夹具，不代表真人试玩或关卡平衡结论。

最终原生压力预热5秒、采样60秒，平均66.305 FPS，P99帧间隔19.924毫秒；采样前置负载最低保持300敌人／600弹体／200掉落，两件真实背包技能、闪避确认、贴地绘制预算及默认设置检查均通过。首次全表碰撞查询版本平均7.450 FPS、P99 147.762毫秒，失败证据保留；没有调整58 FPS／33毫秒门槛或降低负载。迭代期间的10秒控制样本仅用于定位，不替代最终60秒结果，也未重复300秒历史压力。

Windows包输出 `build/Embers-windows-x86_64.zip`，更新前备份为 `build/Embers-windows-before-environment-8e99f1c.zip`。本轮在Windows验证，没有重建或运行macOS包。
