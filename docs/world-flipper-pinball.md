# 任务3：弹射场景与可破坏物

## 地图互动

四图各有12处固定障碍和12个可破坏箱体，其中新增两块初始视野弹板；原10处障碍的ID、位置与数值保留。箱体使用18像素碰撞半径，木桶24生命、宝箱40生命。普通移动、敌人追逐、冲刺和击退共用同一碰撞场，箱体首破立即禁用固定碰撞槽并清理实际寻路缓存，碎片动画不再阻挡通路。出生及首领召唤区保持空地。

冲刺撞击弹板后，主角以原作能量球呈现，叠加当前主角小像，进入1.1秒球化：速度650，可用原移动输入轻微转向；后续弹板增速15%，最高900，并可延长球化，总时长最多1.6秒。球与边界、固定障碍、箱体和敌人按最早接触时间反射，并处理当前步剩余移动；每步最多8次碰撞、每次球化最多12次反弹，结束后把剩余时间交回普通移动。球化不增加冲刺无敌、不给新技能槽，也不刷新冲刺冷却。

球命中敌人造成28×整队伤害属性，连击每次增加10%，最高50%；同一目标命中间隔至少0.15秒。箱子同样受球伤害，首次击碎加入连击。伤害进入独立技能统计，不伪装成武器伤害或怪物击杀。友方飞行武器逐次比较敌人与箱体的碰撞进入时间，箱体消耗该弹体而不触发符文链；伤害技能、爆破和寒焰范围也可击碎箱体。零伤害脉冲仍只控制敌人。敌方飞行攻击继续越过地面障碍。

每箱首次击碎有60%概率掉落，三类等概率：1–3魂屑、8点回复、1.5秒技能充能。每波独立环境随机流由局种子、地图、波次派生，破箱、查看、绘制和拾取不推进商店或战斗随机流。掉落实体上限24，地图最多12箱；回复只消耗实际缺失生命，充能只减少当前拥有的Q/E UID及独立R时钟，不影响冲刺。满血或所有技能已就绪时，对应道具留在原地。它们是地图即时道具，不占背包，不产生第三个后排。新波重建当波环境，未拾取物不跨波携带。

小地图同步显示存活箱体和未消费道具，击碎后下一次事件快照移除障碍标记。弹射状态沿用冲刺状态区与真实冷却条；回弹、箱体受击、破碎和拾取使用有界反馈池，敌方危险预警保持置顶，暂停冻结运动、动画与计时。

## 重建与资源检查

```sh
python tools/fetch_world_flipper_art.py --offline --references
python tools/world_flipper_maps.py --offline
python tools/world_flipper_interactions.py --offline
python -m unittest discover -s tests -p 'test_world_flipper_interaction_assets.py'
```

首次下载可去掉 `--offline`。完整入口按固定源SHA重建全部PNG与元数据；六交互处理器在写入前先校验整个输入族，错误裁片、旋转标记、脚点、时序或末项坏源均不会覆写任何已生成交互文件。新 `.import` 由Godot使用生产路径统一生成，不复制候选缓存旧UID。原始文件、联系图和大体积日志留在 `.tools`，不纳入源码。

独立Python专项覆盖旋转帧还原、透明边缘、整数像素、完整箱桶、适配时序、坏源保护、数据幂等、地标不侵入可玩区和双平台原文件导出。主清单计数与当前地图预览检查同步迁移，旧 `expanded-arena-02` SVG和历史验收记录保留原期望。实际引擎、玩法、原生画面和发行包验收由本任务最终记录补充。

## 性能与验证

物理追帧曾让一次显示帧重复重建多次画面。现在物理仍以60Hz更新，重建请求按显示帧合并；暂停中的设置变更仍立即重画。离屏剔除只跳过完整位于保守相机边界外的特效、魂屑、浮字和尾迹，边界包含震屏、描边、漂移和翼线。所有模拟状态、随机流、600个弹头与环实例及全局家族计数保持，镜头移动后重新显示。

地形一次编译为双精度参数与保守格桶，仍按原减法、除法及平方和判断34个椭圆；没有用倒数或单精度坐标替代边界运算。弹体共用每步候选区域，先做保守包围盒过滤，再计算最早圆面接触时间；最近目标用原生点容器查询，按池槽ID处理同距，排除和非稳定查询保留精确回退。箱体使用独立保守索引，失活立即同步碰撞场。

60秒原生压力维持每个物理步前至少300敌人、600弹体和200拾取物，保留默认闪光、震屏、八武器弹体族与真实符文伤害，并实际使用Q/E/R、25次球化及170次反射。平均61.788 FPS，P99帧耗时26.333毫秒，通过原58 FPS／33毫秒门槛。该诊断会显式将玩家移到真实弹板前，并补齐球化移动造成的远敌回收；具体人为设置完整记录在性能报告中，不能代表自然游玩平衡。

初期原生压力未通过门槛；本轮按实际计时修复重复画面重建与离屏提交，并保留本地失败记录。最终源码、原生与发行包检查、素材校验及截图对照见 `reports/world-flipper-pinball/validation.json`，性能见同目录 `performance.json`。Windows分发包已更新并保留任务2版本备份。此Windows环境未运行macOS构建、真实手柄或硬件音质验收。
