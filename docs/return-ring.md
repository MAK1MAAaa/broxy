# 归魂环与取舍遗物

本轮在既有商店与四法器槽基础上新增归魂环、血契书和引魂烛，内容目录扩展为8种法器、12种遗物，美术版本为`engraved-06`。开局仍选择骨针或幽焰；新内容通过正式商店取得，可重复装备法器，同名法器不合成。

本文件记录规则、验证与边界。当前完整回归、固定种子模拟、原生静帧、300秒压力及Windows新包校验均已完成；上一轮商店锁定版证据单独保留。持续优化目标仍在进行。

## 归魂环的完整航程

发射时在230像素内自动选择敌人，以360像素/秒直线飞出。230是起始索敌范围，不是掉头距离。发射满0.60秒、且弹体尚未消失或取消返航时，魂环改以460像素/秒追随玩家当前位置；玩家移动会改变返航方向。

总寿命从发射开始计为2.40秒，返程不会再增加一段寿命。接触玩家即回收，总寿命耗尽则移除；两者都不回复生命、增加魂屑或返还冷却。法器按自身0.95秒标称冷却独立发射，不等待上一枚魂环回收；实际冷却仍受局内攻速影响。

每枚魂环沿用同一个已命中敌人UID集合，出程与返程共同排除已经命中的敌人。没有符文时，本体最多直接命中2个不同目标；回程不会重置预算或再次伤害首目标。命中预算耗尽、触发爆破或寿命结束都会使弹体消失，因此并非每枚魂环都能完成返航。

## 符文互作

归魂环保留一个可拆换符文槽。本体先穿过首个目标，符文从第二次直接命中开始处理；往返阶段使用同一预算和UID排除规则。

| 符文 | 归魂环行为 |
| --- | --- |
| 无符文 | 最多2个不同直接目标，命中预算耗尽即消失 |
| 贯穿 | 再增加2个直接目标，整段航程最多4个不同直接目标；返程不重置次数 |
| 弹射 | 前两个直接命中使用完整伤害，之后可向尚未命中的邻敌追加最多2跳，每跳保留75%伤害，即基础伤害的75%、56.25%；总计最多4个不同直接目标 |
| 爆破 | 第二个直接命中处触发68像素半径、55%伤害的溅射并消耗弹体；只命中首目标后回收不会补发爆破，次级溅射不再次触发符文 |

弹射只有在实际找到合法邻敌并成功转向时才永久取消返航，之后继续追击邻敌，不会重新切回返程。仅装入弹射符文不提前取消返航；尚未成功弹射时仍按正式返航条件推进。符文额外伤害、直接命中与次级溅射需分别统计，不能把四目标上限当作必定实现的伤害。

## 商店与预览兼容

三件内容进入既有四槽报价池，不新增商品槽或装备容量。归魂环沿用法器购买、出售和免费符文拆换；血契书、引魂烛沿用每种最多3层的遗物规则。

商品可与其他内容一起免费锁定，同时最多2件未售商品，刷新与跨波在原槽保留；锁定不保价，下一波重新定价。缺钱或法器槽满仍能先锁定，成功购买后解锁，重开试炼清空；同种遗物通过另一报价达到3层时，其既有锁定自动失效。完整规则见[商店商品锁定](shop-locks.md)。

遗物“对照”沿用当前属性与购后属性，显示血契书的攻速下降及引魂烛的移速下降，按正式交易计算余额、层数和已装备法器变化。法器商品继续显示每枚伤害、每次枚数和标称间隔；归魂环详情说明返航、全航程不重击和回收无奖励。

符文“预览”沿用已有装入与替换流程，说明第二次直接命中的触发门槛、逐弹目标上限、成功弹射取消返航、爆破消耗弹体，以及替换时旧符文返袋。查询本身不购买、不装配、不推进随机序列；预览值不代表实际DPS。满槽、满袋、余额不足与遗物满层继续使用正式拒绝规则。

## 视觉与资源

归魂环使用中心留孔的冷白三段断骨钩环，血契书使用灰紫皮革与旧金封蜡，引魂烛使用冷青魂焰、骨白窄烛和宽旧金托。图标均为64×64透明SVG，保持中心锚点；形状分别区别月镰、星陨、幽焰与引魂铃。材质与来源见[美术方向](art-direction.md)。

当前共有46项素材：36张SVG、10段WAV，其中图标24枚。原42项资源逐字节保持，新增三枚图标和一张八帧弹体头部图集。图集为512×64透明SVG，每帧64×64对应32×32世界像素；白核、月镰、雷灯、星陨和归魂环纹样预生成，运行时按法器/符文家族以Quad MultiMesh绘制。归魂环没有白核，保留中心留孔；默认半径来自正式资源，其他半径按比例缩放。

弹体视觉版本为`arsenal-atlas-v5`。头部在各自家族尾迹后绘制，取代此前全部白核先绘制、各家族纹样后绘制的顺序；交叠和抗锯齿边缘会有差异，不声称逐像素相同。尾迹、贯穿双轨、弹射环与危险提示通道继续沿用，所有友方弹体绘制仍位于敌方危险提示之前。头部与弹射环的缓冲各自合计不超过1600实例，连同幽焰主体总容量不超过4800；容量下降只调整可见数，必要时回收空余容量给其他家族。
