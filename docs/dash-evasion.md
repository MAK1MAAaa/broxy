# 成功闪避确认

空格冲刺实际用起始保护挡住攻击时，在玩家附近短暂显示“闪避”，配冷青色开口弧和轻音量闪避确认音效。空冲、擦身而过、未引爆的祭仪、范围外爆炸，以及原有受击无敌已经挡住的攻击均不会确认。当前独立音源与优先调度见[技能反馈](skill-feedback.md)，下方历史验收保留原提交范围。

## 判定与边界

确认沿用正式战斗的接触、敌方弹体命中和祭仪引爆入口。只有有限、正值的伤害被当前冲刺保护拦截时才确认；原有0.7秒受击保护优先。同次冲刺无论挡住多少次或多少种攻击，只确认一次。下次成功启动冲刺会清除本次标记，新波重置计数。

确认不造成伤害、不返还冷却、不延长保护，不增加奖励或改变随机数。冲刺仍为0.20秒、660像素/秒、约132像素，起始0.12秒保护，冷却2.4秒；末段正常受伤。接触保护期间继续不触发反冲，弹体按原规则消费，祭仪按原规则只引爆一次。

`CombatSim.dash_evaded(position, origin, source_id, kind)` 提供实际玩家、攻击来源和类型。无效来源坐标回退到玩家位置。`dash_snapshot()` 的 `evaded` 表示本次冲刺是否已确认，`evades` 表示本波确认次数；两者只用于观察，不加入成绩或永久进度。

## 呈现

反馈使用独立单槽状态，不进入伤害浮字池或伤害汇总。文字跟随当前玩家，接近竞技场上沿时放到身体下方，横向限制在画布安全区域；本人、环绕法器和顶栏保持可辨认。提示绘制在玩家之后、承伤提示和敌方危险预警之前。

确认音使用独立的 `evade.wav`，通过 `dash_evasion` 提示键播放，与冲刺和脉冲分别节流；仍复用原12路SFX池。成功闪避优先于普通技能，承伤优先且会停止此前的闪避确认尾音；普通音不会覆盖仍在播放的关键声音。原有 `SoundBank.play` 的声音键和间隔保持。

关闭“受击闪光”会立即取消开口弧，保留正常计时的文字提示；重新开启不会补播旧弧。暂停冻结反馈，停止、结算和新波清空反馈，新一次冲刺开始时也清除上次提示。不增加震屏，不新增静态素材。

如果起始闪避后在冲刺易伤末段实际受伤，新承伤反馈立即打断此前的文字和脉冲，避免把先前成功误读为当前仍受保护；本次成功计数和去重标记保留，提示不会因重复事件复活。

## 验证入口

两平台测试脚本增加 `dash_evasion`、`dash_evasion_world` 和 `dash_evasion_audio`，覆盖实际攻击判定、World呈现生命周期与真实声音池调度。固定画面通过真实Main与物理步制造接触，明确标为非自然对局，不保存档案。预览和压力工具不包含在发行包中。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/test.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run.ps1 --script res://tests/test_dash_evasion_world.gd
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run.ps1 --script res://tools/preview_evasion.gd '--' --case=hit --capture=res://reports/evasion/hit.png
```

预览可选 `hit`、`flash_off`、`resumed`、`miss`、`danger`、`hurt`；后者真实受伤后显示承伤浮字并中断闪避文字。`interactive --hold` 保留窗口，接收系统空格输入以冲向右侧固定敌人。交互夹具可能受到冲刺末段的真实接触伤害，不是无敌演示。

## Windows验收

基于 `6a2fe12`，`./tools/test.sh` 的63套Godot加5个档案诊断入口通过，共26318条断言、32项Python测试；新增真实闪避、World呈现、声音池调度原生专项分别67／75／40条通过。原有冲刺、伤害浮字、危险预警与精简HUD原生检查同时通过。

声音测试在原生模式使用正式 `_ready` 加载的12路音源及既有WAV；headless明确注入相同资源与音源，验证调度算法，不代表硬件听觉结果。两种模式均等待后台音频回收后干净退出，未缩减播放调度验证。

六种稀疏沉沼固定画面经独立审查：命中、关闭闪光、暂停恢复、未命中、危险层和尾段受伤均符合状态。尾段实际损失8生命时，成功计数仍为1，冲刺仍剩约0.033秒，文字和脉冲立即消失。所有画面为1280×720，不代表所有窗口、地图或真人密集威胁辨认体验。

Windows包重新导出并实际启动EXE冒烟。另用匹配的Windows引擎加载导出的PCK和外部测试夹具，验证包内编译代码的成功挡伤及尾段受伤；系统空格输入触发真实接触确认，界面显示“闪避”，从暂停菜单退出且无错误。这项编译包交互与普通EXE冒烟分别记录，预览脚本不随包交付。ZIP CRC、PE和文件指纹验证通过，旧冲刺包保留为 `build/Embers-windows-before-evasion-6a2fe12.zip`。

实际确认反馈压力入口如下，使用默认音量0.65、震屏和闪光开启，不保存个人档案：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/run.ps1 --script res://tools/benchmark_dash.gd '--' --seconds=60 --evasion-probes --output=res://reports/evasion/performance-raw.json
```

该夹具保留300敌人、600弹体、200掉落的步前基础负载，补满玩家生命；每次接受冲刺请求后清除旧受击保护，并在下一步落点额外放入一枚正伤害敌弹，由真实碰撞与冲刺保护决定结果。基础负载计数不包含这一额外弹体。它用于测量真实提示与既有八法器反馈共存的成本，不是自然对局或难度研究。

5秒预热后采样60秒、6587帧：平均109.773 FPS、P99帧间隔18.276毫秒；采样25次冲刺均确认挡伤，含预热共28次，确认单槽峰值1、残影峰值6。每步前基础负载至少300／600／200，最后一步后为300／594／200。采样前、后及当前60项源码指纹一致。未加固定敌弹的初次压力仅在预热确认一次，没有覆盖采样期提示；该结果保留本地，不用来证明新反馈的采样性能。

精简证据与指纹见 `reports/evasion/validation.json` 和 `reports/evasion/performance.json`。首次冲刺版本保留在 `reports/dash/`，仅证明 `6a2fe12` 的对应范围。本轮未重跑完整种子对局或300秒采样，未在Windows重建macOS，未开展长期真人平衡试玩或手柄独占验证。
