# 地图与地形

主菜单可选择四张地图，选定后用于本局全部八波。回到菜单保留本次会话的选择，退出后默认秘仪祭坛。所有地图保持原竞技场边界与出生点，不增加寻路障碍。

| 地图 | 视觉与布局 | 地形效果 |
|---|---|---|
| 秘仪祭坛 | 古石板、烛台、秘仪法阵 | 无减速，保留原战斗规则 |
| 沉沼遗庭 | 斜向苔石踏道、残木、泥水 | 3处泥潭内移动速度−28% |
| 苍霜圣庭 | 破碎冰纹、霜石圆庭、外围冰柱 | 3处霜砂内移动速度−16% |
| 余烬荒原 | 六边玄武岩、暗裂隙、风积灰 | 4处松灰内移动速度−12% |

地形同时影响玩家与所有敌人，包括冲锋、追猎者和首领。按实体中心是否处于椭圆内判定，边界计入；每个模拟步开始时取当前位置，离开后下一步恢复。寒霜减速、追猎者移速与地形倍率相乘，各应用一次。弹体速度、拾取、攻击冷却和伤害不受地形影响，地面无持续伤害。

区域外轮廓就是实际边界；中心与通路保留普通地面。背景生成和运行时读取同一个 `data/arenas.json`，两平台导出均显式包含该文件。场景使用一张1280×720导入纹理，尘屑复用现有22点，未增加动态地形绘制。新图为原创确定性SVG、CC0；原46项素材逐字节保持，合计49项。

本轮精简了标题口号、背包内部编号、重复合成教学、重复烛引介绍及暂停／设置装饰句。地图卡只常驻名称和地形效果；悬停说明双方规则。背包操作集中一条提示，完整键盘操作在“拿起／移动”按钮提示中；符文提示仅在选中符文后显示。购买条件、售价、属性对照、契约风险与拒绝原因仍可直接查看。战斗中取消生命条下方的通知，以及右下角的地图、地形、法器总数和暂停小字；地图选择卡的地形效果与商店操作反馈仍保留。

验证记录见 `reports/terrain-validation.json`。2026-10-27解锁后，同460ccea源码的沉沼／白骨八法器5秒预热＋300秒原生采样平均88.428 FPS、P99帧间隔18.597毫秒，通过性能门槛；只覆盖该压力夹具，其他地图与构筑没有新增性能结论。现有安装包指纹保持，补测记录见 `reports/terrain-performance-validation.json`。原生固定预览可运行：

```sh
./tools/run.sh --script res://tools/preview_arenas.gd -- --arena=mire
./tools/run.sh --script res://tools/preview_rogue.gd -- --case=title --size=960x540
./tools/run.sh --headless --script res://tests/simulate_runs.gd -- --arena=mire --core=frostfire --altar=accept --seed=2026 --count=1
./tools/run.sh -- --benchmark --benchmark-content --arena=mire --benchmark-core=bone_chorus --benchmark-seed=20261026 --seconds=300
```

地图预览是冻结的地形／敌人／危险层级夹具，不是真人对局。正常模拟使用原有走位策略，不会专门绕开减速区；其结果只用于发现流程或明显难度异常，不代表真人胜率。960×540窗口仍以1280×720逻辑视口渲染，截图保持内部画布尺寸。
