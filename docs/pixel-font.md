# 缝合像素字体

本轮将现有游戏字体替换为用户选择的 A「缝合像素 / Fusion Pixel」，使用官方2026.10.25版12px简体中文比例OTF。完整字体随游戏发行，不依赖 Windows 或 macOS 的系统字体。来源、字体与原始下载SHA-256见 [PROVENANCE](../assets/fonts/PROVENANCE.md)。

## 显示规则

`GameTypography` 为界面和战斗提供同一份 `FontFile`。导入设置与运行配置均关闭抗锯齿、hinting、亚像素定位、MSDF和系统字体回退，显式使用1倍oversampling。界面字号统一到12／24／36／48：格内徽标、HUD、商店数值与紧凑按钮使用12；常规大按钮和按需物品详情使用24；大标题使用36／48。详情保留原有滚动和返回焦点，不追加常驻说明。

战斗伤害、闪避和技能结果使用同一字体。普通输出浮字12、承伤24，描边分别1／2像素；原U+2212负号缺字，改用字体具备的ASCII短横线，保留小数与真实承伤数值。背包键位徽标在进入树并取得字体度量后设置20×16尺寸，避免先按默认字体计算而撑高。

## 发行与验证

完整OFL许可及随原发布包附带的Ark Pixel、Cubic 11、Galmuri声明均保留。两平台PCK显式包含四份文件，构建脚本在导出前检查，并复制至发行包 `licenses/fonts/fusion-pixel/`。macOS目录位于应用的 `Contents/Resources/`，复制在签名前完成。

新增字体集成测试通过真实购买和扩容构造6×6背包，覆盖标题、HUD、商店、两种物品详情、长键位、完整内容目录字形及实际伤害浮字，并检查读取界面不改变库存、经济或随机状态。旧测试保留焦点、格位、危险避让和操作断言，只适配新的字体契约。

完整结果记录在 [validation.json](../reports/pixel-font/validation.json)：`./tools/test.sh` 运行94套Godot测试与5种诊断，共33,151条断言，另49项Python测试，均无失败。11套专项原生检查及相同11套PCK检查通过；27组源码／PCK预览逐像素相同。Windows构建与EXE启动检查通过，ZIP的9个文件通过CRC及发行目录逐字节比对，四份字体许可与源码一致；旧包SHA-256与上一轮记录一致。

本地原生预览与导出包截图位于被忽略的 `reports/pixel-font/`，包括标题、设置、按键、暂停、强化、商店及背包状态、HUD和技能反馈。Windows包为 `build/Embers-windows-x86_64.zip`；旧包保留为 `build/Embers-windows-before-pixel-font-1104700.zip`。本轮不构建或运行macOS应用，仅检查其构建脚本语法与许可清单；不声称完成硬件手柄、硬件音频或战斗压力测试。核心规则、内容目录与既有美术素材未变。
