# 符文装入预览与受击材质反馈

本轮修正通用爆破说明对月镰的误导，并让键盘玩家在装入前查看每个法器槽的实际行为和原符文去向。美术继续处理密集敌群的泛白噪点，保留现有42项静态素材、敌方危险层和正式数值。

## 法器特定的装入预览

选择一枚备用符文后，各法器槽提供独立“预览”，原“装入”继续直接生效。预览展示当前与所选符文、旧符文返袋、备用占用，以及每枚弹体的触发命中、理论目标上限或爆破比例。关闭预览后保留所选符文，并恢复来源焦点；预览不会完成装配或消耗随机数。

普通法器在首个直接命中处开始处理符文。月镰先执行一次本体贯穿，第二个直接命中才开始处理符文：

| 装配 | 每枚弹体的行为 |
| --- | --- |
| 月镰＋贯穿 | 最多4个不同直接目标，须实际经过碰撞 |
| 月镰＋弹射 | 先两个100%伤害直接命中，再最多两次转向，伤害为75%、56.25%；需要范围内未命中目标 |
| 月镰＋爆破 | 第二次直接命中时产生68像素、55%伤害的溅射；仅命中一个目标时不会爆破 |

弹射和溅射继续排除本枚弹体此前直接命中的目标；次级伤害不递归触发符文。雷灯的两枚、散魂的三枚分别处理命中、排重和符文，表中的上限不代表一次齐射总上限，也不保证实际命中数或实战DPS。

满备用袋可以直接替换：先移出所选符文，再将旧符文退到袋尾，容量4→4；空符文槽则4→3。同名互换也保留各枚符文的原购买价和身份。`RunState.rune_equip_preview()`仅返回这些事实的深拷贝，正式装配仍调用原`equip_rune()`。

`RuneRules`集中原有的额外2次、230像素弹射范围、75%伤害倍率、68像素爆破半径与55%溅射比例，供正式弹体分支和预览共用；数值没有调整。通用爆破描述改为明确区分普通法器首击与月镰第二击。

## tempered-hit-v1

此前敌人只要`hurt_timer>0`就固定乘以`(1.7,1.5,1.5)`，持续100毫秒且覆盖寒霜状态色。连续命中会让敌人长期泛白，灰紫布料、青灰甲壳和冷色状态难以保留。

正式伤害仍保留原100毫秒计时。绘制仅在最初60毫秒增加亮度：以普通白色或寒霜`b4e9ed`为基础，使用`gain=1+0.22*q²`，其中`q=clamp((hurt_timer-0.04)/0.06,0,1)`。初始、约17/33/50/60毫秒的增益分别为1.220/1.115/1.043/1.006/1.000，三个RGB通道乘相同增益，Alpha保持1。

关闭闪光、计时结束或非有限输入直接使用基础状态色。反复命中最多重回1.22倍，不增加叠加曝光；暂停继续冻结真实模拟计时。主命中刻痕、实际伤害浮字、危险信息顺序、敌人碰撞与攻击保持，没有新增几何、贴图或对象池。

## 复现

```sh
./tools/test.sh
./tools/run.sh --script res://tools/preview_rune_equip.gd -- --case=crescent-blast --capture=res://reports/rune-lab/crescent-blast.png
./tools/run.sh --script res://tools/preview_enemy_hit_style.gd -- --variant=after --case=chilled --capture=res://reports/rune-lab/hit-chilled-after.png
./tools/run.sh -- --benchmark --benchmark-content --seconds=300
```

符文预览另支持`crescent-bounce`、`full-swap`、`volley`、`shop`；调色夹具另支持`normal`、`dense`、`disabled`和`before`。固定夹具通过正式采购、装配、发射和模拟步布置，标注其验证用途，不写个人档案；静止目标和人工叠加危险信号不代表自然关卡。

Windows可使用`tools/run.ps1`并把用户参数分隔符写为`'--'`。性能入口会覆盖`reports/performance.json`，应先备份，另存本轮后恢复历史记录。原始截图、日志和30局逐条结果保留在本地`reports/rune-lab/`，紧凑验收和比较摘要纳入源码。

模拟内容指纹现在包含`rune_rules.gd`。既有策略指纹同时散列整个运行脚本，因此仅添加该来源路径也会改变策略哈希；对照时明确排除两个版本字段，并核对移动/购物策略源码未变及运行脚本仅有该指纹来源行变化，不把哈希变化称作策略算法调整。

## 本轮验证

Windows 11 / Godot 4.7.2完整`./tools/test.sh`通过32次套件调用、10345条Godot断言和22项Python测试。装入纯查询2986条覆盖7法器×3符文×原无/三种旧符文、空/满袋、同名不同身份、非法输入、深拷贝及RNG/信号纯度；真实弹体检查贯穿、弹射衰减、范围与爆破触发/排除。原生装入UI63条、受击材质513条通过，13张1280×720原生图已核对。

UI初测61条有1项失败，实证为正文303px已放入370px视口而测试硬性要求滚动。最终分别验证实际正文完整可见、人工长内容的真实PageDown、还原后滚动范围收回；没有改生产布局迫使它溢出。旧UI引导回归按上下文说明与键盘预览入口更新，正式装入仍一次直接完成。

普通/寒霜/关闭闪光陈列通过8步正式模拟产生15次直接命中、0次追加命中，三档实际计时为0.10/约0.066667/0；密集图通过20步产生3019次直接/5167次追加命中，额外危险夹具已标明。前后模拟、弹体端点、命中和预算记录一致；过期行及关闭闪光的竞技场像素完全一致。RGB各通道均≥245的近白像素，普通746→0、寒霜764→0、密集14965→0；该阈值只描述固定截图的泛白面积，不证明真人动态辨识或打击感。详见`reports/rune-lab/visual-comparison.json`。

同seed2026—2035×三符文30局完成，23胜7败，新核心`467908d843ec`、策略源指纹`1d336100ecaa`。与上一轮`15a5ba98e084`/`7c19c01f20e4`相比，仅排除`balance_version`与`policy_version`后，完整输出、购物trace及报价观测逐字段一致。策略源审计与哈希变化原因见`reports/rune-lab/simulation-comparison.json`。固定旧机器人不使用预览，不据此声称真人选择或整局平衡已验证。
