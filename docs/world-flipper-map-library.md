# 原作地图资料库

当前开放1,261个独立地图层，关联1,102个原关卡编号、158个场景条目，共用150张原生图片。主线第1至11章及其他原作关卡提供可选层；第12章仍因编号墙／单向墙未解而暂缓开放。完整索引保留1,422个原关卡编号和1,658条关卡／图层关联。

主菜单的“世界地图”提供章节筛选、名称／原关卡编号检索和每页六张地图卡片。选择后直接沿用当前游戏的战斗、背包和商店流程；返回主菜单保留本次选择，原有十张竞技场仍可使用。各层独立选择，未把同一关卡的不同图层合并成一张地图。

`data/worldflipper/map_library.json`保留全目录布局及图层身份。只有静态背景配套、唯一边界、整数像素裁切和普通开放墙段通过核验的层才能启动。不可用条目只保留在数据索引中，不能通过UI或`--arena`启动，也不会悄悄替换为其他地图。

地图、物理、镜头和小地图使用同一个选择ID。原始地形以logic坐标保存，统一缩放2／3，对应原生图片的整数4倍像素；每层真实BOUNDS居中于原战斗世界。墙只采用原始WALL相邻顶点的开放段，不自动封口，不给装饰物推测碰撞。重复且完全一致的BOUNDS只取一次，冲突或不完整数据不会开放。

背景由精确引用的PNG、atlas、parts与timeline共同验证，只接受单平面、恒定不透明度和单位变换。恢复图集裁切后的作者画布，以原生尺寸存入`assets/worldflipper/fields/`供不同关卡共享；运行时仅绘制当前图层的裁切区域。复杂矩阵、动画、多层背景、编号墙、单向墙及越出原图的裁切均保留缺口。地图边缘的深色衬底是本作展示方式。

来源为公开历史日服归档的独立ZIP条目，仅下载受限Range并验证条目CRC32、长度、SHA256、PNG块CRC与完整AMF3解码。未下载整个约6.8GB归档，未独立校验上传者提供的全包SHA1。缓存元数据声明1.780.30，最终目录1.780.40的字段和ID对齐不等于逐对象字节一致。原作图像与数据的权利声明继续随发行包保留。

这些地图属于部分适配：原作敌人关卡序列、道具碰撞、美术物件、机关、门、墓地、传送及阶段切换尚未完整重放。目录索引、可选图层、运行时验证和完整移植分开记录，不能把全目录收录算作全部地图已完成。

Godot完整检查使用`./tools/test.sh`，Windows构建使用`tools/build_windows.ps1`。地图压力测试可给`tools/benchmark_dash.gd`传入`--arena=<可玩层ID>`；默认仍使用原来的mire夹具，300敌人、600弹体、200掉落与58FPS／P99不超过33毫秒门槛保持。

普通墙查询使用保留原始段编号的 AABB 树，接触时间相同时仍取原顺序的墙段。投影曲线、交点、已验证空位和导航结果只缓存派生数据；几何、障碍状态或边界改变时失效，失败的配置不会覆盖现有有效场景。路由记录按敌人复用，缓存中的路径数组保持隔离。精确起点和目标的可见连接按原序复用，动态节点增删、局部搜索及必要的完整回退仍保持原调用顺序。

全格直达证明只提前接受已经确认没有墙体的通道；闭环证明只在原路径需要重建时跳过确实不可达的搜索。闭合间距必须已经被真实胶囊端帽覆盖，证明不会向地图、碰撞或小地图补线。上次阻挡墙段也会在每次查询中用原扫掠公式重新核验；过期提示不能直接当作碰撞结果。精确查询与导航回归分别见`tests/test_terrain_wall_queries.gd`、`tests/test_wall_navigation_cache.gd`。

弹体绘制复用当前武器／符文批次的引用和常量，保留原实例顺序、Float32 缓冲区及颜色运算。常规视口内双端完整可见的拖尾省去重复的包围盒构造；跨边、非有限值和极大坐标继续使用原查询。独立冻结旧绘制器的对照覆盖18帧、600枚弹体、63个家族、重建和对象复用；它与完整战斗逐步对照均不替代原生帧率验证。

Windows发行包可直接运行相同压力夹具，输出路径应为可写的绝对路径：

```powershell
./build/Embers-windows-x86_64/Embers.exe -- --wf-dash-benchmark --seconds=60 --hero=alk --arena=wf_main_4_4_4_l0 --backpack-skills --hero-skills --output=D:/Github/broxy/reports/map-pressure.json
```

源码的`tools/benchmark_dash.gd`与发行入口共用`Node`实现，两者都在`process_frame`记录帧间隔、在真实World物理步前补足压力负载。报告区分调试／发行引擎和来源；短测不能替代60秒验收，预热期最大帧间隔单独保留。该入口不读写个人档案。

构建需要Python 3.10或以上；可用`BROXY_PYTHON`指定解释器。两个平台的构建脚本都会生成并检查`assets/diagnostics/dash_benchmark_sources.json`。文本指纹规范为UTF-8／LF，二进制保留原字节；源码入口复核当前文件，发行入口记录嵌入的构建来源，再由外部验收绑定EXE／PCK。清单排除自身和覆盖账本以避免哈希循环，压力报告另外记录运行时账本的实时原字节SHA。

固定画面验收比较源码、PCK与实际发行EXE的20组原生截图，逐项核对RGBA像素、绘制前后状态和无个人档案读写。普通窗口为1280×720，`--small`的窗口与客户区为960×540；两种窗口均保持1280×720内部渲染，保存的PNG也为1280×720。浏览器焦点签名使用浏览器内的子节点索引路径、控件名称与类型，排除构建间不同的自动祖先名称，仍保留无焦点及浏览器外焦点的状态。

完整模拟对照固定使用四张地图各180个真实物理步，逐字节比较约定范围内的模拟状态；它不测量渲染帧率。正式性能验收分别运行阿尔克、五件装备的法露伽及87墙复杂地图，均须预热5秒、采样60秒，并通过全部真实施放与负载检查。三份报告必须由同一份实际发行EXE／PCK产生，由启动回执绑定命令、报告和启动前后的二进制SHA。

本轮完整检查通过130套Godot与5项档案诊断，共107,112条断言、272项Python测试；源码与PCK各16项原生专项通过，20组源码／PCK／实际发行EXE的RGBA及状态哈希完全一致。三组60秒发行压力依次为114.651／100.773／59.520 FPS，P99为15.682／17.186／27.332毫秒；所有负载、真实施放和功能检查均通过，发行包10个文件的CRC、解包字节及素材声明一致。完整证据见[地图验收](../reports/world-flipper-map-library/validation.json)。本轮未构建或运行macOS，手柄提示与焦点为模拟验证。

源码变更会使旧运行证据过期。本轮撤销旧验证标记后重新执行完整检查和原生对照，生成新的`runtime-validation.json`并绑定到覆盖账本；绑定后19项覆盖审计全部通过，包括原先失败的目录身份审计及无原始缓存审计。发行构建和最终压力报告继续绑定同一份来源清单、实时账本与EXE／PCK字节。
