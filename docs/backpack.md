# 秘术背包与盒装物品

武器、遗物和未镶嵌符文统一存放在占格背包中，替代四法器槽、四份备用符文和每种遗物三层的旧容量规则。背包内的所有武器自动参战，所有遗物生效；已镶嵌符文随武器存放，不额外占格。竞技场、波次、经验强化与现有内容风格继续沿用。

实现基于 `a865a01`，保留暗黑秘术风格，Windows本轮已完成规则、界面与原生验收。

## 存放与整理

- 初始6列×4行，可花32、48魂屑分别增加一行，最多6×6。扩容不重排已有物品。
- 物品有独立UID、位置、朝向和阶级。长武器与大型法器占用不同矩形格；遗物较小，未镶嵌符文占1格。
- 购买只自动找空位，不自动合成。按行查找，优先原朝向，再尝试旋转；无法完整放入时不扣款、不改变报价或库存。
- 商店内可拖拽、点选或键盘拿起物品，旋转并放置；非法落点保留原库存，Esc取消。移动不改变武器的战斗顺序。
- 商品锁定与四件报价保留。背包暂满时仍能锁定商品，整理、合成、出售或扩容后再购买。

## 合成与升阶

同种类、同名、同阶的两件物品可手动合成为一件高一阶物品，最高三阶。目标UID和摆放位置保留，源物品消耗，累计买入价相加，形状不随阶级变大。

武器单枚伤害与遗物属性权重为一阶1倍、二阶2倍、三阶4倍。两件合成主要释放空间，单件变强；不额外改变射数、冷却或本体贯穿。符文升阶增加行为数值：贯穿/弹射追加目标2、3、4个，爆破半径68、78、88像素，溅射倍率55%、65%、75%；弹射距离230及每跳75%伤害保持。

合成武器时优先保留目标符文；目标未镶嵌时继承源符文。两边都有符文时，源符文必须完整退回背包，先验证空间再提交。换符文利用拿起符文留下的空格存放原符文，拆卸则需要真实空位。附着与松散符文共用唯一UID，不复制或销毁。

## 出售与属性

武器、遗物和松散符文都可出售，按累计实际买入价的50%向下取整退款，至少保留一件武器。出售武器先验证已镶符文的退回位置。合成或出售不会免费补血，生命只夹到新的上限；购买生命遗物仍按生命上限增量补充。

遗物不再限制三层，按实际存放物品及阶级权重计算。大量负面遗物时仍有属性下限：伤害/攻速倍率0.25、移速60、生命上限1、拾取范围16、护甲0。预览和实际战斗使用相同数值规则。

## 操作与画面

沿用1280×720参考分辨率与viewport等比缩放／留黑边策略，窗口最小960×540。左侧四件报价，右侧始终保留完整6×6网格；未解锁行使用暗格。详情单独滚动，合成目标与关键预览优先显示。盒子保留已有物品轮廓、种类色、阶级和镶符标记；合法／非法落点同时给出文字反馈。

鼠标拖拽可移动、合成或装符；也可Tab选择盒子，在详情中拿起，再用方向键、R、Enter、Esc整理。失败保留物品原位与拿起状态，焦点回到网格；商店换页、快照变化与旧按钮均受会话和UID检查保护。战斗HUD最多显示8枚图标及总数，全部存放法器仍参与发射；结果页滚动显示完整构筑。
