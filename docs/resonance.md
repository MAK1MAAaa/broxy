# 遗物共鸣与秘术匣材质

本轮沿用8种法器、12种遗物与暗黑秘术美术，在占格背包中增加摆放策略。法器与遗物矩形共边时，遗物Ⅰ／Ⅱ／Ⅲ阶分别提供3%／6%／12%该法器的局部伤害加成，每把法器最多18%。正长度共边才成立，角接不算；同一遗物跨多个接触格仍只计一次。每把法器独立计算，不传导，松散符文不提供共鸣。

遗物原有全局属性仍按阶级累加。最终单枚伤害为基础伤害×法器阶级倍率×当前全局伤害倍率×（1+该法器共鸣），攻击间隔与符文命中预算保持原规则。一个遗物可以支持多把相邻法器；合成、出售、旋转和移动都可能改变邻接，合成不再保证保留原两件的总局部伤害。

规则查询与实际发射共用UID投影。购买预览使用自动寻找的真实落点；放不下时不虚构新增共鸣。遗物满包假设对照保留全局属性变化，但明确缺少可用落点。合成分别展示源与目标原本的伤害，并计算真实合成后布局；附着符文退回、失败回滚与个人档案隔离沿用。

盒子以暗皮革底、薄金属角扣与内框高光分层；阶级同时使用罗马数字和刻痕，已镶符改用对应符文图标徽章。共鸣只沿真实共享边显示，选中或整理时强调相关连接，避免满包形成常亮线网。装饰不接管输入，网格50像素单元与2像素按钮内缩保持。既有46项SVG／WAV及头部图集保持原字节。

## 与另一构筑系统的整合

当前版本同时支持秘术核心、烛引目标优先与遗物共鸣。自动主弹在发射时按该法器UID加入共鸣一次；白骨侧弹继承同一加成后再乘55%，寒焰按实际弹体伤害乘50%，次级效果不递归触发。移动／旋转／合成与赠品提交均按真实背包重新投影。组合验证、30局和本次Mac交付见 `reports/macos-main-integration-validation.json`；本文此前的包、性能与断言数字保留各历史阶段范围。
