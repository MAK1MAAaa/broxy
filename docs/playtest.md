# 首轮真人试玩

目标是确认新玩家能理解符文改变攻击方式，并愿意再次开局。这里记录待执行方案，不代表已经完成五人试玩。

## 执行

1. 在测试者自己的Windows x86_64或Apple Silicon Mac启动对应平台已验证的应用，仅提供“WASD移动，法器自动攻击”说明；让其自行选择起始法器。记录包版本，不混用尚未重建的macOS旧包与Windows当前玩法。
2. 记录第二次商店结束时是否已装配符文；第三波开始前，请其解释法器行为发生了什么变化。
3. 观察第一次购买、刷新、符文装配、卸下、出售的理解与错误。记录每次波末总操作耗时。
4. 记录死亡波次、来源、是否看清预警及是否理解失败原因。
5. 结束时询问是否愿意立刻再玩一局、偏好的符文和最困惑的操作。
6. 当前Windows版另记录首个波内强化的波次/战斗时间、是否理解暂停与继续、选择耗时和是否觉得打断频繁；询问能否解释拾取范围如何影响强化时机。保留原话，不用机器人升级次数代替主观体验。
