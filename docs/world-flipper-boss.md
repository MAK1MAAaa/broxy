# 独立首领战与弱点打断

第八波保持90秒倒计时、1500首领生命及原首领ID。显示名与原作外观统一为瑞西塔尔。取消首领波的普通周期刷怪，由实际首领招式控制召唤；其他七波的刷怪和敌人数值保持。当前首领战使用本项目独立规则，原作图片与招式设计的来源分别记录。

## 血条与空间

首领HUD位于1280×720基准画面的 `(240,104,800,50)`，处于原86像素顶部栏下方，避开右侧小地图。仅在实际首领存活时显示，直接读取生命、阶段、蓄力进度和破防时间；没有UI自行推进的时钟。原顶部栏内血条已移除。首领存活时浮字安全上缘为174，普通战斗保持110；实际世界上缘人物头部仍有空间。小窗口沿项目原viewport缩放，键盘／手柄焦点不被血条或弱点图截取。

## 蓄力与破防

开场等待1.8秒，招式之间恢复1.4秒。蓄力和破防期间首领固定位置，接触仍伤害玩家，但接触反冲不再推走首领或弱点布局。每次蓄力的目标、方向、弱点和预警位置在开始时冻结。

| 招式 | 蓄力 | 实际攻击与第二阶段 |
| --- | --- | --- |
| 翠岚协奏 | 2.5秒 | 第一阶段三个半径88落点依次触发；第二阶段改为五点风暴，节奏和覆盖形状改变 |
| 荆棘回廊 | 2.2秒 | 第一阶段三条纵向伤害带、两条安全通道；第二阶段四条横向伤害带和一条中央安全通道 |
| 林灵合唱 | 2.3秒 | 第一阶段两翼召唤，第二阶段围绕锁定目标三角召唤；跨招式存活上限分别4／6只 |

根须伤害带长度840、宽112，安全道宽128；渲染与碰撞均为有限方端矩形，玩家身体按10像素半径与矩形求最近点接触，端点之外不会被胶囊式延长判定。根须活跃0.45秒，风暴各点活跃0.25秒。已发布攻击拥有独立生命周期，打断下一次蓄力不会清除历史攻击。

风暴有3个弱点，其他招式2个，均可任意顺序攻击。弱点碰撞半径13，第一阶段24生命、第二阶段32生命；完整96像素源格以32像素显示，标靶可见直径约26，匹配实际命中范围。它们通过确定性地面查询避开全部固定障碍与箱体，保持彼此间距，再原子回写FSM位置；发布版同样真实执行回写，不将状态修改放入debug断言。出生、边界与重新开始均有回归覆盖。

全部弱点击破后立即取消当前蓄力，进入1.5秒破防；恢复0.85秒后继续下一招。破防只使真实首领生命受到的后续伤害乘1.35，普通敌人、箱体和弱点均不放大。血量降至50%时锁定第二阶段，当前正在蓄力的招式保留原布局，下一次采用第二阶段序列。

## 命中与结算

弱点是独立目标，不放入敌人池、不产生击杀、经验或魂屑。武器自动瞄准、追踪与落星的最近目标可优先选择存活弱点。飞行攻击在同一线段上比较敌人、箱体、弱点的最早圆面接触时间；弱点使用 `cast_id:uid` 排除键，与敌人数字UID隔离。弱点与箱体／敌人完全同时接触时弱点先结算。穿透仍消耗原有预算：Ⅰ阶贯穿最多3个直接目标；点命中不自行生成爆破、寒焰或弹跳链。

伤害技能、已有范围爆炸和球化使用相同几何攻击弱点；零伤秘术脉冲保持控制定位。每个范围批次只处理一次当前存活UID，过期招式的UID或cast被拒绝。球体从重叠弱点向外离开时逐点排除，再查询前方其余目标，避免漏检。

每步先推进FSM，再处理所有Q/E/R、球和友方弹体及爆炸，最后才释放到期招式。因此蓄力截止帧仍可击破最后弱点；末点立即进入破防，同帧后续命中读取新的倍率。首领死亡或失败结算先停止FSM并清理召唤物，不奖励回收，也不再发布待释放攻击。

召唤物沿用蓝波露外观，生命为对应波次普通敌人的60%，接触伤害75%，计入真实敌人容量。其固定初始计时与坐标不消耗战斗或商店随机流；存活数量跨cast计数，与340敌人池容量同时受限。满员时跳过请求，不延后补生。自动策略补充寻找弱点及避开冻结攻击几何，其轨迹版本单独标识，不能与旧策略胜率直接比较。

## 原作素材与表现

素材层为 `world-flipper-fan-07`：68条来源、65张PNG、2份元数据。仅新增一张原作弱点图集与独立布局JSON，任务3的64张PNG保持。白色、红色、破碎三状态来自官方试玩通用战斗图集；完整四象限、十字臂及破碎parts按来源矩阵还原，中心统一 `(48,48)`。来源、SHA与适配见 `tools/world_flipper_weakpoints_sources.json`、`assets/worldflipper/PROVENANCE.md`，本轮没有重画敌人、角色、封面或地图。

蓄力最后30%切换红色标靶，实际命中提供短亮反馈，击破使用原作破碎帧0.22秒；表现池最多3点，暂停冻结，关闭闪光仍保留实际标靶与破碎状态。当前蓄力预警、已发布攻击、弱点与技能反馈保持各自生命周期，敌方危险层最后绘制。
