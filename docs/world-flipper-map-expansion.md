# 官方试玩地图补充

本批次补入官方试玩资源中此前缺少的三个场景，使当前接入的官方试玩场景从四组增加到七组。新增名称为本项目的中文展示名，原作资源身份以路径为准。

| 游戏 ID | 名称 | 原作场景路径 |
| --- | --- | --- |
| `town` | 星见镇 | `world_town/town_street` |
| `throne` | 光之王座 | `world_light/light_castle_throne` |
| `tower_peak` | 魔塔之巅 | `world_evil/evil_tower_top` |

原有 `reliquary`、`mire`、`glacier`、`ashland` 保持稳定 ID、地形数值及地图 PNG 字节。三张新图均保留3444×1800可活动范围、3780×2192完整场景画布和1280×720起始镜头；各新增六处地形、十二处固定障碍和十二个可破坏箱体。原有三十四处地形保持，总计五十二处。原有地图上的所有障碍、箱体、移动、碰撞、索路和掉落规则沿用，新增地图使用独立的地形摆位和物件组合。

素材来自[《弹射世界》官方试玩](https://worldflipper.jp/demo/)的公开 `src/assets/production/battle/field/` 图像。来源 URL、SHA-256、原始尺寸、裁切和落点完整记录在 `tools/world_flipper_maps_sources.json`。`tools/world_flipper_maps.py --offline` 使用本地校验过的原图重建，统一采用原像素整数2倍和镜像拼接。王座图的中央红毯也取自该原图，沿实际世界 x640 铺设，不做插值或重新上色。建筑、王座台座和灯柱仅放在可活动范围之外，避免地面图像暗示不存在的碰撞物。

归一化后的三个场景与各自的起始镜头缩略图位于 `assets/worldflipper/maps/`。正式原生验证需要实际进入每张新图，检查背景、地形、小地图、障碍、破箱及 Boss 波次；仅有源图或目录不代表可玩场景验收。

新增 Python 检查 `tests/test_world_flipper_map_expansion.py` 不访问网络和原始缓存，覆盖三图原像素与缩略图一致性、地形/物件布局、外缘建筑落点、红毯真实源像素与非法配置。Godot 场景回归由主代理统一执行。

这七组仅覆盖目前核对的官方试玩场景，不能视为日服最终版的全部地图。完整资料目录另记录在 `data/worldflipper/catalog.json`，包含247条场景定义和1422条布局引用；这些资料记录不等于可玩的关卡，也不附带完整场景 PNG 和地形二进制。后续需要继续获取并核对主线、活动与首领变体的源图和地形，再逐批接入可玩关卡。原图版权与非开放许可状态沿用项目的同人素材声明。
