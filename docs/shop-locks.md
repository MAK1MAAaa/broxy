# 商店商品锁定

商店最多免费锁定2件未售商品，供玩家保留需要稍后购买或等待腾出装备位置的内容。锁定商品仍占原来的四个商品槽，不增加报价数量，也不直接购买或装备。

本轮基于本地提交`15b992c`完成，核心指纹为`prototype-0.1.0+724650407895`。行为、原生界面与Windows分发验收见下文，机器可读汇总见[validation.json](../reports/shop-locks/validation.json)。

## 操作与状态

| 状态或操作 | 行为 |
| --- | --- |
| 锁定、解锁 | 均免费，不扣魂屑，不增加刷新次数；解锁不会立即替换眼前商品 |
| 锁定上限 | 同时最多2件未售商品；已锁商品始终可解锁，达到上限时需先腾出锁定名额 |
| 缺少魂屑 | 仍可锁定；购买条件与价格继续显示，锁定不抵扣售价 |
| 法器槽或备用符文满 | 仍可锁定，便于先出售、装配或等待后续波次；购买本身仍遵守容量限制 |
| 刷新商店 | 有效锁定商品保留原槽，其余槽重新报价；刷新仍按原规则收费 |
| 跨波返回商店 | 有效锁定商品保留原槽，并按新波次重新定价；其余槽生成新商品 |
| 购买成功 | 对应商品标为已购买并自动解除锁定，释放一个锁定名额 |
| 购买失败 | 保留原商品与锁定状态，不额外扣费或占用容量 |
| 同种遗物达到3层 | 该遗物已永久不可再买，清除其锁定，不再跨刷新或跨波保留；不生成第四层效果 |
| 重开试炼 | 清空上一局全部锁定；锁定不写入设置、最佳成绩或中途存档 |

已售商品不能锁定。若通过另一张同种遗物商品买到3层，原先锁定的该遗物也失去保留资格。缺钱、满法器槽与满备用符文属于可恢复条件，不按永久失效处理。

## 价格与保底

锁定只保留商品，不保留旧价格。同一波内刷新仍使用当波售价；跨波后按当波价格规则重新计算，不能通过锁定长期保留前期低价。刷新费用继续随本店刷新次数增长，下一波重置；锁定与解锁不会改变该计数。

首店至少有一件法器，第二店至少有一件符文。有效锁定商品若已满足当店保底类别，则计入保底；否则从未锁槽补足，不覆盖锁定商品原槽。锁定上限为2，四槽商店仍保留可生成新商品的位置。

## 界面与美术

沿用 `engraved-05` 暗黑秘术卡片：锁定操作位于商品名称第一行，使用“已锁”标记与“解锁”按钮；锁定卡片使用旧金边框，保留类别文字与道具图标。锁定状态不只依赖颜色，页脚明确“锁定跨波保留，价格随波次调整”。

锁定数量显示在“本次供奉”同一行。名称按钮、计数和底部提示复用现有空间，1280×720布局不新增卡片行高，不挤压购买、遗物对照、装备预览和开始下一波按钮。购买受阻与锁定已满分别表达，不能把满锁误写成商品不可购买。

小标记使用现有Control文字与框线，不引入外部位图，不改变战斗素材、角色碰撞或危险信息层级。
