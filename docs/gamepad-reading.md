# 手柄阅读与轻推冲刺

本轮补全长内容的手柄阅读，并修复有效模拟移动与冲刺选向不一致的问题。

## 阅读操作

LB向上、RB向下，每次按下翻动当前区域可视高度的80%，首尾自动限边；按钮松开不翻页，不设置按住连翻。无需先把焦点移入滚动区域，翻页保留原焦点，A仍执行原控件操作、B按原层级返回。

| 当前画面 | 翻页目标 |
| --- | --- |
| 遗物对照 | 属性与法器对照表 |
| 符文装入预览 | 逐弹规则与返回说明 |
| 秘术抉择 | 核心、契约和路线内容 |
| 商店，未打开覆盖层 | 当前物品详情 |
| 结算 | 最终构筑 |

有覆盖层时只滚动该层，设置、按键捕获及暂停菜单不会翻动底层背包。持物整理、原生鼠标拖拽和商店等待重建期间禁用翻页，结束后恢复。翻页只改变滚动位置，使用现有页内库存查询；不购买、合成、装符、重建页面或推进冷却。

长内容外侧保留阅读提示；有效肩键会将提示切至手柄，键鼠操作后恢复滚轮和键盘说明。设备切换不重置已读位置。旧滚轮及内容聚焦后的PageUp／PageDown、Home／End继续可用。

## 轻推冲刺

输入层已有0.20圆形死区，但战斗逻辑曾额外用方向长度平方大于0.01判定面向和冲刺。以向上轻推至0.24为例，死区后强度约0.05，角色已经慢移，却仍按旧面向冲刺。

普通面向与冲刺现共用“有限且非零”判断。普通速度继续保留模拟强度；向上、四向和小幅斜向均沿实际输入冲刺。回中没有运动输入时保留最后面向；非法冲刺输入沿用原拒绝。基础冲刺仍为0.20秒、660像素／秒、完整132像素、起始0.12秒保护及2.4秒冷却。

## Windows专项结果

旧战斗源码上，`analog_dash`的71条断言有32条失败，真实Main输入流程45条有4条失败，均定位为轻推面向／冲刺方向。最小修复后，原生71／45条全部通过；普通模拟强度、基础132像素距离与保护计时由同一专项核对。

`gamepad_reading`原生227条、headless223条通过，包括真正由鼠标手势启动的GUI拖拽、单次肩键从键鼠提示切为手柄、两种实际窗口尺寸1280×720和960×540。遗物、符文、背包详情及结算构筑的1280×720自然滚动范围分别为583、104、280、34逻辑像素，解析RB均到达末尾；固定画面完成独立复核。秘术抉择另验路由与原键盘翻页，内容能容纳时不虚构溢出。

背包固定场景为正式购买的10把法器、Ⅲ阶弹射符文与裂砂漏，共占34格；结算场景为八类法器占满36格。结算伤害贡献来自显式发射的正式弹体在固定高血静止目标上的碰撞，最后受击通过`take_damage()`设置，用于最紧布局检验；这些都不代表自然关卡难度。

同种子沉沼／白骨齐鸣／原途／接受追猎的普通与显式Q策略各3局，六局均通关，除战斗源码版本标识外所有结果与上一版相同。模拟不构造阅读UI，翻页与轻推方向另由原生专项覆盖。

`./tools/test.sh`完整门禁为79套Godot及5个档案诊断入口，共29359条断言、32项Python测试通过。旧遗物对照、符文预览、秘术抉择和设备提示另做原生回归，PowerShell及Bash入口语法检查通过。

Windows重新导出，实际EXE启动并完成冒烟截图。匹配引擎加载导出PCK和外部夹具，轻推方向71条、Main输入45条通过，四组翻页预览均到末尾；PCK夹具与普通EXE启动分别记录。ZIP的CRC、成员字节及x64 PE检查通过，432个既有素材、数据和历史报告文件保持，51项美术／音效不变，上一版ZIP保留。精简指纹与证据见[验收记录](../reports/gamepad-reading/validation.json)和[模拟对照](../reports/gamepad-reading/simulation.json)。

本轮未连接实体手柄，输入使用软件事件；未重建macOS，也未重新采集性能压力数据。既有系统工具字母键身份差异的限制仍见[键位版记录](controls.md)，本轮没有将其解释为实体键验收。
